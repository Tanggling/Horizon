### [OpenAI announcement draws attention to claimed ETH refutation and physics proofs](https://openai.com/index/building-scientific-understanding-with-academic-communities/) ⭐️ 8.0/10

An OpenAI announcement titled “Announcing three new discoveries in mathematics, computer science, and physics” is drawing attention for claims concerning the Exponential Time Hypothesis \(ETH\), Yang–Mills existence, and QCD. A commenter quotes a claimed deterministic algorithm for exactly counting satisfying assignments of arbitrary k-CNF formulas that, for each fixed k ≥ 2, uses polynomial space and runs in time \(n + m\)^\{O\_k\(1\)\} · 2^\{n/\(log n\)^\{1/2 + o\(1\)\}\}, where n is the number of variables and m the number of clauses; if correct, this would refute ETH without establishing P=NP. Another commenter quotes OpenAI as saying its models produced natural-language proofs for Yang–Mills existence and QCD, and that a Lean formalization of Yang–Mills existence was completed. The supplied material contains only a related link and truncated discussion, not the announcement or proofs, so the results’ correctness, precise scope, and formalization coverage remain unverified here.

hackernews · jonluca · Oct 26, 21:35 · [Discussion](https://news.ycombinator.com/item?id=50251344)

**「What the Exponential Time Hypothesis asserts」** The Exponential Time Hypothesis asserts that deciding whether a 3-CNF Boolean formula is satisfiable requires exponential time in the number of variables in the worst case. An exact counting algorithm with the subexponential runtime quoted in the comments would refute that hypothesis if correct, since counting satisfying assignments also determines whether any exist; it would not by itself establish P = NP, because subexponential time need not be polynomial time.

**「Conditional hardness bounds would need reassessment」** If the algorithm quoted in the comments is correct, researchers could no longer use the Exponential Time Hypothesis as a valid premise for computational hardness bounds; the conditional proofs themselves would not thereby become erroneous. The claimed running time remains superpolynomial, so it would not establish P=NP or, by itself, demonstrate a practical SAT solver. The supplied excerpts do not establish the algorithm’s correctness.

**「Community discussion」** Commenters emphasized ETH’s role as an assumption behind conditional hardness bounds in parameterized complexity, expressing surprise at the claimed refutation. One asked whether such a result should increase confidence in P=NP while explicitly acknowledging that disproving ETH would not itself establish that equality; no substantive answer is included in the supplied comments.
